# Maparr Documentation

Welcome to the official documentation for Maparr, the self-hosted offline map manager for home servers.

## Getting Started

- **Install**: run the [Docker image](https://github.com/fyrek1d/maparr) (`ghcr.io/fyrek1d/maparr:latest`) or clone and `docker compose up -d`. See the [README](../README.md) for the quick start.
